# 选项③ 实验：攻 multi_defect + 证据采纳（prompt v2.3）

> 日期：2026-09-30 | 控制变量：B2 kb 级索引 + qwen-plus + 一遍法，**只换生成器 prompt**（v2.2→v2.3）
> 实验脚本：`exp/exp_e2e_kb_v23.py` | 逐题明细：`exp/exp_e2e_kb_v23_result.json`

## 一、v2.3 prompt 改了什么
针对「multi_defect 漏根因 / 跳过证据」两类失败，强化三处：
1. 规则1 改「**逐条穷尽每 kb 全部根因，禁止概括跳过**」
2. 加「**证据采纳平等**」规则（默认全部采纳，禁止因长块偏好忽略他证据）
3. 加 multi-kb few-shot（强制按 kb_id 逐条列举）

缓存 key 含 `PROMPT_VERSION`，自动全量重跑，不与 v2.2 串味。

## 二、结果：v2.3 是「净负」实验（strict 主指标回退）

| 指标 | C(v2.2) | D(v2.3) | Δ |
|---|---|---|---|
| **strict 正确** | **79/160 (49.38%)** | 73/160 (45.62%) | **−3.76pp / −6 题** |
| lenient 可用 | 98/160 (61.25%) | 106/160 (66.25%) | **+5.00pp / +8 题** |
| multi_defect strict | 10/30 (33.3%) | 11/30 (36.7%) | +3.3pp / +1 题 |
| ambiguous strict | 20/30 (66.7%) | 20/30 | 0 |
| single_defect strict | 21/50 (42%) | 21/50 | 0 |
| param strict | 20/40 (50%) | 21/40 | +1 |

**逐题转化（C→D strict）**：improved 19 / regressed 22 / same 159
- 跌出 correct 的 15 题：correct→partial 10、**correct→wrong 5**
- 进入 correct 的 9 题：wrong→correct 3、partial→correct 6
- 净 −6 题。**分类别净变化全为负或持平**（multi −1 / param +1 / single −1 / ambiguous −2）

**结论**：v2.3 的「采纳平等 + 枚举 + few-shot」让模型**更爱多生成根因**（lenient +8），
但同时引入**更多非 gold / 假根因**，strict（要求「全 gold 且无假」）反而崩。
**已回退 src/answer_generator.py 到 v2.2**，生产维持最优 49.38%。

## 三、关键重定位：检索截断不是主瓶颈，**生成层才是**

之前诊断「multi_defect 37% 败在检索漏 gold、prompt 救不了」需修正——那是**子集缺漏**口径，
与「任一 gold 命中」不同。算 strict 真正需要的「**全部 gold ⊆ top-k**（可行性上限）」：

| 覆盖口径 | k=5 | k=8 | k=10 | k=12 |
|---|---|---|---|---|
| multi_defect 全 gold⊆top-k | 18/30 (60.0%) | 21/30 (70.0%) | 22/30 (73.3%) | 22/30 |
| 全量 全 gold⊆top-k | 129/160 (80.6%) | 137/160 (85.6%) | 143/160 (89.4%) | 143/160 |

对照实际：C 组 strict 全量 **79/160 (49.4%)** vs 可行性上限 **129/160 (80.6%)**。
→ **生成层缺口 ≈ 31pp（80.6%→49.4%），远大于检索截断缺口。**

- multi_defect 在 k=5 仅 60% 题目全部 gold 进上下文（12 题检索注定不可达），
  k=10 升到 73%（+4 题可达）——**top-k 增大是「小杠杆」（最多 +4 题 multi 可行性）**。
- 但 50 题**全部 gold 已在上下文**却仍非 strict 正确 → 纯生成问题（穷尽纪律 / 假根因）。

## 四、证据采纳缺口（诊断里点名的第二项）
- v2.3 想用「采纳平等」规则修跳过证据，结果**反向**：模型采纳更多 → 也采纳更多错的。
- 真实「检索已覆盖 gold 但模型未穷尽」的题在 C/D 两组都占大头（即上面 50 题生成缺口的主体），
  不是「偏好长块 KB024 跳过 KB016」那种单点问题，而是**系统性穷尽不足**。

## 五、下一步建议（按 ROI）
1. **保持 v2.2 为生产 prompt**（已回退，49.38% 仍是最高 strict）。v2.3 留作失败记录。
2. **不要再用「放宽采纳」思路**——它系统性引入假根因。应走**收紧**方向：
   结构化输出（按 kb_id 逐条列采纳根因）+ 禁止证据外根因 + 输出后校验。
3. **top-k=10 小实验**（~30min，¥4）：用 v2.2 prompt 隔离检索效应，预期 multi +4 题可行，
   但需防上下文变长稀释穷尽（可能 strict 不涨甚至微跌）。
4. **真正的大杠杆在生成层**：50 题 gold 全在上下文却答不对，需比 prompt 更硬的约束
   （如：抽取 gold 根因 → 强制逐条回填 → 判官校验），这超出纯 prompt 调参。

## 六、当前最优基线（重申）
B2 kb 级索引 + qwen-plus + 一遍法 + **prompt v2.2** = **strict 49.38% (79/160) / lenient 61.25% (98/160)**
（注：含 KB016 空参照失真 1 题；去失真后真实 48.75% 更可信）
