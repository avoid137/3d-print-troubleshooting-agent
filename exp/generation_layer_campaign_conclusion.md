# 生成层提准战役结论（v2.3 / v2.8 / v2.8b）

> 时间：2026-09-30｜背景：KB 级索引重构（B2 + qwen-plus + 一遍法）已定 SOTA 基线，
> 检索召回 90%@5 已到顶，剩余严格准确率缺口在**生成层**。本战役系统尝试三种生成层改造，验证是否能在
> **strict 零回归安全门**下超过当前生产路径。

## 一、生产基线（不可动的参照）

- 路径：B2 kb 级索引 + qwen-plus + 一遍法(v2.2 prompt) + **append-only 完整性回填(v2.7)**。
- **SOTA = 54.37%（87/160 in-scope strict correct），零回归**（回填全开每题都跑，77 道答对题 0 退化）。
- lenient = 69.37%（usable）。
- 严格天花板：gold⊆top-5 = 80.6%（129/160），即「生成完美」理论极限；当前 54.37% → 生成层缺口约 26pp。

## 二、三次生成层改造与结果

| 方案 | 方法 | strict 率 | vs 回填 | 回归(须=0) | 结论 |
|---|---|---|---|---|---|
| v2.3 | 两遍法（Pass1 相关性**过滤**抽根因→Pass2 作答） | 45.62% | −8.75pp | 22 | ❌ 净负（过滤丢 gold） |
| v2.8 | 确定性全量**枚举**+单步 LLM 穷尽作答（草稿有 `skipped` 排除权） | 56.87% | +2.50pp | **23** | ❌ 不可部署（skipped 丢 gold） |
| v2.8b | v2.8 草稿 + append-only 回填保底 | 56.87% | +2.50pp | **23** | ❌ 等价 v2.8（回填救不了显式拒绝） |

## 三、根因（为什么"重写"都过不了零回归门）

**统一根因：任何「让模型做相关性排除」的机制都不可靠，会把 gold 根因一起误删。**

1. **v2.3**：Pass1 让模型「筛相关根因」→ 把 gold 根因过滤掉 → correct→wrong 净负。
2. **v2.8**：Call1 确定性枚举（不丢 gold）是对的，但 Call2 给了模型 `skipped`「跳过无关项」权
   → 模型把 gold 根因也跳了（答案显式写「以下证据关联性弱、未采纳：KBxxx」）→ 23 道回归。
   - **枚举阶段不丢 ≠ 作答阶段不丢**：确定性铺开全部根因，仍可在作答时被排除。
3. **v2.8b**：回填只补「草稿**默默漏掉**」的相关根因，不推翻草稿**主动 skip** 的根因
   → 混合方案对 skip 回归**完全无效**（实测与 v2.8 严格等价，regress_vs_v28=0、improve_vs_v28=0）。

**唯一安全模式 = append-only 回填**：只追加、不删除、不重排 → 下行有界（最多多加噪声、绝不丢已答对 gold）
→ 经生产级全量实验证零回归。这就是为什么它是当前 SOTA 且可部署。

## 四、关键方法论（沉淀为 skill：rag-generation-ab-safety-gate）

1. **零回归安全门优先**：生成层改动必须对**全部 in-scope**（含已答对题）跑 treatment，
   `correct→非correct` 必须 = 0 才折进主路。净 Δpp 会掩盖回归，单独看误导。
2. **确定性枚举 > 模型过滤**：想让模型更穷尽，用「从 KB 确定性拉取全部根因」喂给它，
   别让模型做相关性过滤/排除（必丢 gold）。
3. **重写式改造的死结**：只要保留模型的「排除权」，就过不了零回归门；去掉排除权又引入噪声致 wrong。
   两难之下，append-only 回填是当前模型/prompt 下的实践最优。
4. **代理 502 长跑续跑**：DashScope 经 SteamTools 代理易隧道 502；结果须逐题增量写盘、
   resume 剔除 error 项重试、call_model 重试 5×退避 2s；偏样本（中途失败只统计成功部分）会失真，须补全全量再下结论。

## 五、最终裁决

- **SOTA = 回填路径 54.37%（87/160），可部署，零回归。**
- v2.8 / v2.8b 留作**失败记录**（代码保留在 `src/answer_generator.py` 的 `generate_v28` / `generate_v28_with_backfill`，
  不接入生产主路）。
- 生成层在 strict 零回归质量门下**已到顶**；继续硬攻「重写」收益预期为负或等价。
- 若未来要再突破：须换更强/更可靠的接地策略（如两遍法但 Pass1 用确定性规则而非 LLM 过滤、
  或检索侧再提精把 gold⊆top-5 从 80.6% 往上推），而非当前 prompt/枚举微调。
