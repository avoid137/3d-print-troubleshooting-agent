| 项 | 结论 |
|---|---|

## 一、风险 → 改进措施（逐条对应上一轮 §3）

### 1.1 🔴 近重复泄漏（高风险）·处置升级

**上一轮方案**：pHash + group-aware 折划分。
**问题**：我查到一条直接反驳「pHash 够用」的证据 —— SSRN 7395570（4 个医学影像数据集、5 seed × 5 fold = 25 次配对跑）用 HAM10000 的**真实病灶 ID**（少见地可独立验证）发现：

> **pHash 只召回了 3.3% 的真实同病灶图像组** —— 作为重复检测代理，其可靠性本身依模态而变。

这条证据的三个含义：
1. **不能只信 pHash** → 需第二检测器兜住「pHash 漏掉的语义级重复」；
2. **阈值不可照抄** → `Hamming ≤ 5` 是通用默认，必须用**人工标注的重复/非重复样本**自标定；
3. **泄漏影响是数据集特定的** → 不能预设「影响小」或「影响大」，**必须实测**（这正好支持我们「两套划分都报、差值即泄漏幅度」的设计）。

**改进措施**：

| # | 措施 | 具体做法 |
|---|---|---|
| 1 | **pHash 粗筛** | dHash/pHash 64bit，阈值取保守值（如 ≤ 5），快速缩小候选对 |
| 2 | **DINOv2 特征精筛** | 对 pHash 未命中的图，用冻结 DINOv2 提特征算余弦相似度，**捕获「不同角度拍的同一实物」**（pHash 对视角变化脆弱，CLIP/特征类方法才能抓） |
| 3 | **阈值自标定** | 人工标 ~50 对（重复/非重复）→ 选能兼顾精确率与召回率的阈值，不照抄 5 |
| 4 | **连通分量聚组** | 相似度图上取连通分量 → 每个连通分量作为一个 group |
| 5 | **group-aware 折分配** | group 整体分配到同一折（`StratifiedGroupKFold`）；分层约束在 group 层面做 |
| 6 | **双划分对照** | 报告 `folds_stratified`（普通分层）与 `folds_grouped`（去泄漏）两套 macro-F1，**差值 = 泄漏幅度的量化估计** |
| 7 | **可审计** | 落盘 `data/p1_folds.json`：每张图的 group_id、fold 归属、两套划分各是什么；并输出聚类报告（哪些图被折叠、依据是什么） |

> 纪律：折叠阈值只做**一次**，以普通分层下的分数作参照；若 group-aware 分数掉得太多（如 > 10pp），**不要**为了好看而放松折叠——那正是泄漏存在的证据。

### 1.3 🟡 Cracking / Off_platform 映射概念混淆

**改进措施**：

## 二、更好的方法与数据集（外部证据）

### 2.1 ✅ 方法：冻结骨干 + 轻量分类头 > 全量微调（小样本场景）

这是本轮**最有价值的发现**，有两类独立证据：

**证据 A · 同领域直接对照（最相关）**
Bast et al. 2026, *Int J Adv Manuf Technol* 144:2047–2059（DOI `10.1007/s00170-026-17844-w`），2026-04-10 发表，题目正是 FFF 缺陷检测：
- 方法：**预训练 ResNet-50 只做特征提取 + kNN 分类**（不微调）
- 类别：extrusion errors / layershifts / stringing / error-free（4 类，含无缺陷）
- 结果：**各类F1 0.757~0.990，加权平均 0.812**
- 数据集：Zenodo `18628777`（见 §2.2），**三个相机角度**拍摄

**证据 B · 跨领域机制验证**
- 植物病害（PlantVillage 训练 → PlantDoc 测试）：**冻结 DINOv2 线性探针 51.1%，比全量微调 EfficientNet-B0 高 +23.4pp**；全量微调把跨域准确率从 50.6% **拉低到 29.4%**。即：**在小数据上微调骨干会破坏预训练特征、损害泛化**。
- 海洋物种识别：同样条件下 **DINOv2 Linear Probe 的 macro-F1 与全量微调持平，但可训练参数少 4 个数量级**（约 1,500 vs 17.6M）。
- 字体细分类（394 类）：**线性探针 36.6% 远低于 LoRA 98.7%** —— 反例说明：**特征线性可分性因任务而异**。缺陷是视觉形态问题（介于两者之间），**必须实测，不能假设线性探针够用**。

**综合判断**：P1 应做**三级对照**，而不是只跑一种：

| 级别 | 方法 | 预期 | 成本 |
|---|---|---|---|
| L1 基线 | 冻结骨干特征 + **kNN**（论文同款） | 最快，零标注成本 | 分钟级 |
| L2 主力 | 冻结骨干 + **线性探针**（DINOv2/ResNet50） | 小样本通常最优 | 分钟级 |
| L3 上限 | **全量微调** EfficientNet-B0 | 上限最高，但小样本易过拟合 | 现有方案 |

**这三条正好构成「P1 自己的消融实验」**，比单跑一个微调模型信息量大得多，且成本极低（L1/L2 几乎不花时间）。**且 L1 恰是同领域 2026 年论文验证过的路径，方法论可引用、不是自己拍脑袋。**

⚠️ 口径纪律：若 L1/L2 优于 L3，**写「小样本下冻结特征优于全量微调」并引用 Bast 2026 与植物病害两处证据**；不得说成「我们比论文好」。

### 2.2 🟡 数据集：Zenodo `18628777`（2026-02，CC BY 4.0）

**已核实事实**（Zenodo API + 引文交叉验证）：

| 项 | 内容 |
|---|---|
| 标题 | Quality Control in Additive Manufacturing: Image Dataset for Defect Detection in Fused Filament Fabrication |
| 作者 | Bast, Scherer, Wahl, Naumann, Dartmann, Didas（特里尔应用科技大学 / FH Aachen） |
| 发布 | **2026-02-13**（v2.0.0） |
| **许可** | **CC BY 4.0** ✅（论文参考文献中明确标注 "License CC BY 4.0"，符合本项目「许可明确才用」红线） |
| 体量 | **48.4 GB**（base 19.6 GB + test 12.6 GB + additional 16.1 GB） |
| 内容 | 高分辨率原图 + 裁剪图；**含无缺陷件**；3 个相机角度拍摄 |
| 缺陷类 | extrusion errors / layershifts / stringing errors（+ error-free） |
| 关联论文 | DOI `10.1007/s00170-026-17844-w`（2026-04-10） |
| 代码 | gitlab.rlp.net/ISS/realtime-defect-detection-in-additive-manufacturing |

**与 DC-02R 的对比**：

| 维度 | DC-02R（现主集） | Zenodo 18628777 |
|---|---|---|
| 类数 | 5（含 Warping/Cracking/Off_platform） | 4（extrusion / layershift / stringing / error-free） |
| 含无缺陷 | ❌ | **✅** |
| 视角 | 单一 | **3 个相机角度** |
| 许可 | MIT ✅ | **CC BY 4.0** ✅（需署名） |
| 体量 | 6.3 GB | 48.4 GB |
| 已知缺陷 | 🔴疑似同实物连续拍摄（泄漏风险待测） | 无同类公开报告 |
| 对我们的价值 | 覆盖 Warping/Cracking/Off_platform（知识库映射需要） | **可跨数据集验证泛化** |

**关键判断：两者是互补，不是替代。**

- ❌ **不能替代 DC-02R 做主集**：Zenodo 没有 Warping / Cracking / Off_platform，这三类直接对应知识库条目（`KB024 Warping`、`KB049`、`KB002/KB028`），换了主集**映射层就断了**。
- ✅ **但它是极好的外部验证集**：在 DC-02R 上训完，到 Zenodo 上测，**跨数据集差值就是泛化能力的量化证据**。这直接解决 HANDOFF §6.5 里「第三方标注泛化验证（需外部人力）」这一项 —— **不用外部人力，用另一个公开数据集就能做**。
- ✅ **还能补一个产品级能力**：含无缺陷件→ 可做「正常/异常」门控，而不只是 5 类互分。这对 Agent 落地很关键（用户拍一张正常件不该被硬判成某个缺陷类）。

**建议处置**：
- **P1 主集仍为 DC-02R**（映射层需要它的 5 类）；
- **Zenodo 18628777 登记为 DC-07**（外部验证集 + 正常件门控数据源），列入 `data/dataset_cards.md`；
- ⚠️ **下载需谨慎**：48.4 GB，先只下 `test_data.zip`（12.6 GB）做验证，够用即可，不必全量下；
- ⚠️ **CC BY 4.0 必须署名**（Bast et al., Trier University of Applied Sciences, DOI 10.5281/zenodo.18628777），且需下载数据集本身并遵守 Zenodo 使用条款。
- 需核实（下载后确认）：**是否有实物/part 级 ID**。若没有 → 同样面临泄漏问题，需用同一套pHash+DINOv2 流程处理。

### 2.3 ⛔ 不推荐的新数据集（评估后排除）

| 数据集 | 为什么不选 |
|---|---|
| **3D-ADAM**（NeurIPS 2025 D&B，14,120 扫描 / 27,346 缺陷实例） | 数据质量高（4 种工业深度相机、217 个真实零件、专家验证标注），但**是 RGB+3D 点云 + 缺陷分割掩码的异常检测任务**，不是我们的 RGB 图像 5 分类；且 PLA 单材料限制。作为「未来扩展」写进报告可以，**不作为 P1 数据源** |
| 3D 打印 1557 张 Sequential CNN 研究（报告 99.68%） | 虽 2026 年发表，但 **99.68% 准确率对缺陷分类而言高到不可信**，典型的单次划分+ 潜在泄漏产物。**不可作为对标数字** |
| Cambridge 127 万张 | 原计划 P2 用，体量与任务都不匹配，本轮不评估 |

### 2.4 方法层面的两个补充建议

1. **多层特征融合**：缺陷既有纹理（拉丝）也有几何（翘曲、层错位）。骨干取**倒数第二层 + 浅层特征拼接**再做线性分类，比单一全局池化特征更能覆盖两类形态。成本几乎为零，实现约 20 行。
2. **TTA（测试时增强）**：水平翻转 + 多尺度推理，通常 +0.5~1.5pp，推理成本可接受。**但必须先在去泄漏划分上验证增益**，增益小于噪声就如实报「等价」——这正是 P0 学到的教训。

## 三、改进后的 P1 方案（替换上一轮 D3）

### D0 环境 → D1 防线 → D2 数据 → **D3 三级对照** → D4 映射 → **D5 外部验证**

### D3 · 三级对照（替代原「只跑微调」）

```
L1 冻结骨干 + kNN（论文同款，分钟级）
L2 冻结骨干 + 线性探针（DINOv2 / ResNet50，分钟级）
L3 全量微调 EfficientNet-B0（分钟级，保留作上限对照）
```
每级都跑**两套折划分**（stratified / grouped），共 3 × 2 = 6 组主结果。

**报告口径**：
- 主指标macro-F1 **均值 ± 标准差**（必报）
- **组内差异 < 2pp 一律判「等价」**，不宣称优劣（沿用 P0 的 ±7pp 纪律，小样本下标准差可能更大，须先看标准差再下结论）
- 诚实说明 L1/L2 若胜出→ 引Bast 2026 + 植物病害两处证据解释机制

**新增验收门**：
| 门 | 内容 |
|---|---|
| 去泄漏 | 报告两套划分的差值（泄漏幅度）；**group-aware 分数是主口径** |
| 折数 | 5折 ×2 种子（若时间允许）→ 标准差更可信；5 个折太少估不准均值 |
| 最弱类 | Off_platform recall ≥ 0.70（仍保留） |
| 阈值自标定 | pHash/特征阈值来自人工标注样本，非照抄 |

### D5 · 外部验证（新增，替代原「需外部人力」项）

1. DC-02R 训练的模型 → 在 Zenodo 18628777 的 `test_data` 上评测 → **报告跨数据集差值**。
2. 借助其**无缺陷件**，加一版「正常/异常」门控评测。
3. 差值是真实泛化能力的量化证据，也是**比单数据集分数更硬的对外口径**。

⚠️ 类别体系不同（Zenodo 4 类 vs DC-02R 5 类），只能取**语义可对齐的子集**（extrusion ↔ 挤出类、stringing ↔ Stringing、layershift ↔ Layer_shifting）比较，并明确说明对齐关系与不可比之处。

### 建议同步修订的验收标准

| 项 | 原定 | 建议改为 | 理由 |
|---|---|---|---|
| macro-F1 | ≥ 0.80 | **≥ 0.80 保留，但增设「与同领域可达水平对照」** | Bast 2026 同领域加权平均 0.812、单类低至 0.757。0.80 对 5 类是合理线，但**不能拿论文里的 87% 当自己的目标**，那会造成不必要的挫败与造假冲动 |
| 主口径 | 未区分 | **group-aware 划分为主口径**，stratified 作泄漏对照 | 诚实且可辩护 |
| 泛化 | 无 | **必须报跨数据集差值**（若 Zenodo 数据到位） | 单数据集高分≠泛化，这是 2026 年的共识 |
| 消融 | 无 | **L1/L2/L3 三级必做** | 成本极低，信息量远高于单跑一种 |
